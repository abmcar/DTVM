% Two parallel inputs (hand-curated rules, enumeration) feed Z3 admission;
% only the production-rule branch is deployed to the JIT, while the
% enumeration branch is a measurement/audit channel that does NOT drive
% production rule maintenance (per §3.2 of the paper).

\caption{Two-tier system overview. Hand-curated production rules
(\textbf{70} dMIR + \textbf{13} x86) pass an offline Z3 admission gate
and become the compiled rule set deployed by the JIT (dMIR matcher
followed by x86 CgIR cleanup); correctness is gated by 5{,}884
differential Cancun tests. In parallel, canonical-LHS enumeration
submits 853 capacity-run candidates and produces \textbf{1{,}966}
audit-channel admitted rewrites whose canonical left-hand sides cover
all 70 production rules; the audit channel is a measurement output and
is \emph{not} deployed to the JIT.}
\label{fig:architecture}
