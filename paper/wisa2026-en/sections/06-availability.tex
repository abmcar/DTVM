\section*{Data and Code Availability}

Rule sets, offline Z3 admission checks, evaluation scripts, and data
are available in an anonymous repository upon request to the program
chairs and will be de-anonymized upon acceptance. CI runs the production
dMIR validation tests on every change to the rule file.
