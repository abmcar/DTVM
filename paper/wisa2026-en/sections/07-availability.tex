\section*{Data and Code Availability}

The rule synthesis scripts, rule sets (JSON and Z3 query files),
evaluation scripts, and experimental data are released to reviewers
through an anonymous mirror; the URL is provided in the double-blind
submission materials and will become a de-anonymized public release upon
acceptance. The equivalence check of each rule is re-executed
automatically by the continuous-integration pipeline whenever the rule
file changes.
